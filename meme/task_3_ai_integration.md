# Task 3: AI Integration

## Objective
Enhance the Weather Web Application with AI-powered features to provide smart, personalized weather insights or summaries for the user.

## Requirements
- Integrate an AI service API (e.g., Google Gemini, OpenAI) to process raw weather data into natural language insights.

## Sub-tasks
- [ ] Define the specific AI feature (e.g., natural language weather summaries, smart clothing recommendations, or travel activity suggestions based on the forecast).
- [ ] Set up API keys and environment variables for the chosen AI service in the Python backend.
- [ ] Create a new backend endpoint (e.g., `GET /api/weather/ai-insights`) that passes the current weather data to the AI model and retrieves the generated response.
- [ ] Update the frontend UI to include an "AI Insights" or "Smart Summary" section within the main dashboard.
- [ ] Implement the frontend logic to fetch and display the AI-generated text seamlessly.
- [ ] Ensure AI insights load gracefully without blocking the main weather data rendering (e.g., using loading states).
